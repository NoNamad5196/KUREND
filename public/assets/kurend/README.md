# 제공된 정적 자산

사용자 첨부 ZIP의 단독 캐릭터 16개, 차량 2개, 소품 2개, 캠퍼스 배경 1개를 원본 그대로 보관합니다. `manifests/sources.json`의 치수와 SHA-256으로 출처와 원본 보존을 확인할 수 있습니다.

캐릭터·차량·소품은 실제 알파를 가진 PNG입니다. 배경은 별도 RGB PNG이며 UI·말풍선은 코드로 배치합니다. 화면에서는 정적 이미지만 사용하고, 졸업복·학사모가 포함된 졸업 원본을 그대로 표시합니다. 별도 학사모·졸업장 파일도 보존하며 추가 합성하지 않습니다.

화면 대응표와 보존·검증 설명은 [정적 자산 교체 문서](../../../docs/STATIC_ASSET_MIGRATION.md)를 참고하세요.
