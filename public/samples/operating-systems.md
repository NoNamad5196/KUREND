# 운영체제: 프로세스 스케줄링

프로세스는 실행 중인 프로그램이다. 각 프로세스는 코드, 데이터, 스택과 실행 문맥을 가지며 운영체제가 프로세스 제어 블록(PCB)으로 상태를 관리한다.

## 프로세스 상태

생성된 프로세스는 준비, 실행, 대기 상태를 오간다. 실행 중 입출력을 요청하면 대기 상태가 되고, 입출력이 끝나면 준비 상태로 돌아온다. 타이머 인터럽트가 발생하면 실행 중인 프로세스가 준비 상태로 이동할 수 있다.

## CPU 스케줄링

CPU 스케줄러는 준비 큐에서 다음 프로세스를 선택한다. FCFS는 도착 순서대로 실행하지만 긴 작업이 앞에 있으면 평균 대기 시간이 길어진다. SJF는 짧은 작업을 우선해 평균 대기 시간을 줄일 수 있지만 실행 시간을 미리 알아야 한다. 라운드 로빈은 시간 할당량마다 프로세스를 교체해 응답성을 높인다.

## 문맥 교환

문맥 교환 때 운영체제는 현재 프로세스의 레지스터와 프로그램 카운터를 PCB에 저장하고 다음 프로세스의 문맥을 복원한다. 이 시간에는 사용자 작업이 진행되지 않으므로 할당량을 지나치게 짧게 잡으면 오버헤드가 커진다.
