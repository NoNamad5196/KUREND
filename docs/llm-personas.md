# AI 후배 대사·데모 가이드

숫자와 시험 형식은 `src/contracts/game.ts`의 `CHARACTERS`, 행동 사양은 `src/lib/llm/personas.ts`를 기준으로 한다. UI 문구도 이 말투와 맞춘다.

| 후배 | 말투와 반응 | 시험 | 합격선 |
|---|---|---|---:|
| 남학생 | 밝고 자연스러운 `~습니다/~입니다/~것 같습니다`. 고른 설명을 빠르게 기억하며 정답 여부를 즉시 교정하지 않는다. | 객관식 4지선다 5문항 | 60 |
| 여학생 | 친근한 해요체 `~요/~같아요/~했어요`. 차분하게 의미와 원인을 묻는다. | 서술형 의미 설명 5문항 | 70 |
| KU | 기존 호칭·대사·성격 유지. 애매하면 잘못 이해한 내용을 자기 말로 자주 확인한다. | 이유·비교·응용을 포함한 서술형 5문항 | 80 |

후배는 사용자가 실제로 가르친 것 이상을 알면 안 된다. 질문과 강의노트의 자료 정보가 답안에 흘러들어가면 안 된다. 사용자 설명이 비어 있으면 모른다고 답한다. KU의 반복 학습은 같은 말을 기계적으로 세 번 시키지 않고 설명의 명료도에 따라 달라진다. 후배가 시험을 본다. 사용자가 문제를 푸는 화면이 아니다.

## 학습 대화와 시험 출력

남학생·여학생의 일반 학습 반응에는 호칭을 붙이지 않는다. 남학생은 “아하, 알려주신 대로 기억하겠습니다!”, 여학생은 “아, 그런 의미였네요!”처럼 설명에 반응한다. “선배님”은 직접 질문하거나 도움을 요청할 때만 가끔 사용한다. 매 답변의 prefix로 반복하지 않는다. `normalizePersonaAddress`는 직접 호칭을 보정하며 인용한 사용자 설명과 “선배가 맡은 역할” 같은 일반 어휘를 보존한다. KU의 “선배” 호칭과 기존 말투에는 이 제거 규칙을 적용하지 않는다.

- 학습 대화: `personas.ts`, `prompts/respond-turn.ts`에서 캐릭터 말투와 질문·리액션을 적용한다. 첫 질문은 `personaQuestion`으로 만든다.
- 시험 출제: `prompts/prepare-session.ts`에서 자료에 근거한 서로 다른 핵심 개념 5개를 선정하고 `o1`~`o5`와 `q1`~`q5`를 일대일로 연결한다. 캐릭터 말투 없이 “설명하시오”, “고르시오” 같은 문제 형식을 사용한다.
- 시험 답안: `prompts/write-exam-answer.ts`에서 저장된 사용자 설명만 근거로 답을 작성한다. persona·호칭·인사·리액션을 넣지 않으며 객관식은 번호만, 서술형은 내용 중심의 평서문으로 표시한다.
- 채점·피드백: 판정과 근거를 명확하게 유지한다. 채팅·시험 출력에는 Markdown 굵게 표시 문법을 사용하지 않으며 출력 정리와 화면 표시에서도 방어한다. 사용자 원문·인용 근거·코드의 실제 내용은 보존한다.

새 후배 챕터 세션은 모두 핵심 학습 개념 5개와 시험 문제 5개다. 추가 확인이나 KU의 반복 설명으로 대화 횟수는 더 늘 수 있다. 졸업시험은 10문항, Run 없는 연습 세션은 3문항이며 이미 저장된 과거 시험은 그대로 유지한다.

## 기존 3문항 데모 회귀 대본

경제학원론 **수요의 이해** 챕터의 기존 3문항 fixture를 검증하는 입력이다. 로컬 테스트의 `usr_demo2` 시드 계정과 KU 설정으로 사용해 온 대본이며, 운영 로그인 화면에는 체험 계정을 제공하지 않는다. 아래 입력 문자열은 `fixtures/demo-script.ts`와 그대로 일치시킨다. **58점·100점은 기존 3문항 데모/연습 fixture에 대한 기대 결과이며, 새 5문항 후배 시험의 점수를 보장하지 않는다.**

1. **Scene 3, 잘못된 설명:** `가격이 오르면 사람들이 더 많이 사니까 수요도 늘어나.` → KU: `잠깐만 선배. 그러면 가격이 오르면 수요도 늘어난다는 거야?`라고 오해한 채 되묻는다. 이 턴은 배운 개념으로 저장하지 않는다.
2. **Scene 4, 핵심 개념이 빠진 설명:** `수요량은 한 가격에서 사려는 양이야. 다른 조건이 같을 때 가격이 오르면 수요량은 줄고 가격이 내리면 늘어. 이것은 같은 수요곡선 위에서 움직이는 거야.` → 가격과 수요량은 설명했지만 가격 이외의 수요 결정요인이 빠졌다. 기존 3문항 데모 stub의 기대 결과는 **58점**이다. 이 결과를 KU Run의 LIFE 판정 fixture에 연결하면 FAILED이며, LIFE가 1이면 GAME OVER로 이어진다. Run 없는 연습 세션 자체는 LIFE에 영향을 주지 않는다.
3. **만점 경로:** `수요는 일정 기간 동안 각 가격에서 사려는 의사와 능력이 있는 양의 관계 전체이고, 수요량은 한 가격에서 사려는 양이야. 다른 조건이 같을 때 가격이 오르면 수요량은 줄고 가격이 내리면 늘어. 그래서 가격과 판매량이 같이 늘었다고 해서 법칙이 틀린 게 아니라, 소득이나 유행 같은 다른 조건이 바뀌었는지 먼저 확인해야 해. 재화 자체의 가격 변화는 같은 수요곡선 위 이동이고, 소득 변화와 기호 변화와 소비자 수 변화처럼 가격 이외 조건이 바뀌면 수요곡선 자체가 이동해. 같은 가격에서 사려는 양이 늘면 수요 증가로 곡선이 오른쪽으로, 줄면 수요 감소로 왼쪽으로 이동해.` → 기존 3개 목표를 빠짐없이 가르친 3문항 데모 fixture는 **100점**을 낸다. 새 5문항 시험에서는 선정된 5개 개념에 대한 실제 설명과 생성된 문제를 기준으로 채점한다.

시험을 시작하기 전에 위 설명이 모두 사용자 메시지로 저장되어야 한다. 후배 답안과 채점은 저장된 사용자 설명만을 근거로 한다.
