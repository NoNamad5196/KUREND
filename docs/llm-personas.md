# AI 후배 대사·데모 가이드

숫자와 시험 형식은 `src/contracts/game.ts`의 `CHARACTERS`, 행동 사양은 `src/lib/llm/personas.ts`를 기준으로 한다. UI 문구도 이 말투와 맞춘다.

| 후배 | 말투와 반응 | 시험 | 합격선 |
|---|---|---|---:|
| 남학생 | 짧고 밝게, 단순한 확인 질문. 모순이 뚜렷할 때 드물게 되묻는다. | 객관식 4지선다 | 60 |
| 여학생 | 차분하게 의미와 원인을 묻는다. “왜 그런가요?” | 서술형 의미 설명 | 70 |
| KU | 솔직하고 서툴게. 애매하면 잘못 이해한 내용을 자기 말로 자주 확인한다. | 서술형과 이유·비교·응용 | 80 |

후배는 사용자가 실제로 가르친 것 이상을 알면 안 된다. 질문과 강의노트의 자료 정보가 답안에 흘러들어가면 안 된다. 사용자 설명이 비어 있으면 모른다고 답한다. KU의 반복 학습은 같은 말을 기계적으로 세 번 시키지 않고 설명의 명료도에 따라 달라진다. 후배가 시험을 본다. 사용자가 문제를 푸는 화면이 아니다.

## 데모 대본

체험2 계정, 경제학원론 **수요의 이해** 챕터, KU 후배를 사용한다. 아래 문장은 시연 입력의 기준이다.

1. **Scene 3, 잘못된 설명:** `가격이 오르면 사람들이 더 많이 사니까 수요도 늘어나.` → KU: `잠깐만 선배. 그러면 가격이 오르면 수요도 늘어난다는 거야?`라고 오해한 채 되묻는다. 이 턴은 배운 개념으로 저장하지 않는다.
2. **Scene 4, 핵심 개념이 빠진 설명:** `수요량은 한 가격에서 사려는 양이야. 다른 조건이 같을 때 가격이 오르면 수요량은 줄고 가격이 내리면 늘어. 이것은 같은 수요곡선 위에서 움직이는 거야.` → 가격과 수요량은 설명했지만 가격 이외의 수요 결정요인이 빠졌다. 데모 stub 시험 결과는 **58점, FAILED**다. 체험2의 LIFE가 1이면 GAME OVER로 이어진다.
3. **만점 경로:** `수요는 가격별 구매 의사를 나타내고 수요량은 한 가격에서 사려는 양이야. 다른 조건이 같을 때 가격이 오르면 수요량은 줄고 가격이 내리면 늘어. 재화 자체의 가격 변화는 같은 수요곡선 위 이동이고, 소득 변화와 기호 변화와 소비자 수 변화처럼 가격 이외 조건이 바뀌면 수요곡선 자체가 이동해.` → 세 목표를 빠짐없이 가르친 경우 데모 stub은 **100점, PERFECT**를 낸다.

시험을 시작하기 전에 위 설명이 모두 사용자 메시지로 저장되어야 한다. 후배 답안과 채점은 저장된 사용자 설명만을 근거로 한다.
